## System boundary

```text
Go Platform
  durable product/research state
  Artifact Registry metadata
  Attempt / ProductRevision lifecycle
  promotion, scheduling, durable workflows

Python Engine
  compiler semantics
  model inference/training
  geometry/ML research
  proof logic and stage execution

C++ Runtime
  package consumption
  playback/deformation/render hot paths
```

The rule is: **Compiler owns meaning. Platform owns time, durability and product state. Runtime consumes qualified artifacts.**

## State model

```text
Git/main          = code truth
Attempt           = research truth
ProductRevision   = production truth
Workflow Engine   = durable execution truth
Artifact Registry = immutable typed artifact identity/dependencies
Proof/Qualification = promotion eligibility
```

Product render/playback should consume a qualified ProductRevision without rerunning model inference. Product compile for a new subject runs the required inference/Compiler construction path unless an exact semantic cache hit is proven. Research Attempts may incrementally reuse exact qualified upstream artifacts.

## Product-quality authorities

- **Geometry** — surface/silhouette/topology/addressing.
- **Mechanics** — rig, skin, deformation, contacts and motion.
- **Appearance** — complete source-preserving 2D art and appearance qualification.
- **Presentation** — qualified source-owned editable presentation/grouping without invented semantic identity.
- **Runtime** — deterministic consumption of qualified product artifacts.

A visually incorrect puppet does not pass merely because its mechanics are valid.
