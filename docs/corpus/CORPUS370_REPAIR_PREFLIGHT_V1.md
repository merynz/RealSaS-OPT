## Independently measurable surface

`CORPUS370_FAMILY_TRUTH_EXECUTION_PLAN_V3.json` is a new, not-yet-released research
graph. Stage50 acquires the exact observation-admitted import and independently
reconstructs its source-world geometry. It runs the existing geometry/normal
producer and independent court, and emits its own family evidence index before
kinematic or texture work. A later calibration error cannot erase that evidence.

Stage51 measures capabilities using the existing strict observation-rest apparatus.
Known typed failures are retained with hash-bound logs in an accounting envelope;
it does not fabricate a successful TeacherScene. Resource errors and unexpected
Python failures propagate. Stage49 consumes successful calibration normally, or
uses an independent missing-target court to mask absent mechanical/response/TESSA
targets while retaining Stage50's surface families. No zero actions/weights/UVs or
numeric placeholder targets are created.

The new `source_surface` manifest segment must provide an exact
`admitted_import_geometry` file reference. The old export preserved that hash in
admission but did not necessarily carry the original import bytes. The next input
export must bind those bytes, not assume that the replacement runtime can recreate
an identical JSON file. The exact hash guard remains active.

## Local oriented probes

`local_oriented_probe_v1.certify` permits only isolated nearest-anchor primitives.
It uses a conservative spatial candidate bound and exact point/triangle distances;
ties, closer competing surfaces, invalid anchors and unresolved offsets are masked.
Both conflicting rows in the parallel-surface counterexample are absent. A
certificate is local oriented-distance evidence, never global sign or occupancy.
This helper is tested but is not a completed trainer integration: the old139
runtime overlay must not generate unconditional ±epsilon labels anymore.

## M target and remaining pilot

The native product dynamic proof already measures rest intersections and rejects
new pairs or increased overlap severity (`motion_dynamic_proof_v2.py`). TESSA V5
instead globally rejects all rest intersections. A source-relative teacher contract
must be versioned, independently checked, and scoped separately from physical
collision freedom or product motion qualification. The V5 criterion and all old
FAIL evidence remain unchanged by this patch. The contact-contract candidate and
its representative source replay are still pending.

The bounded evidence-slice workflow is read-only and performs no Blender or truth
execution. It runs on a reviewed workflow change to main or an explicit manual
request. It verifies the existing full input bundle and exports at most
12 selected source packets, native preparation/import diagnostics and128MiB of
uncompressed files. No broad Drive inventory or full corpus is copied. This is
needed because the connected provider rejects the1.6GB base ZIP above its256MiB
per-file transport limit. The resulting authenticated artifact makes the small
pilot reproducible without another whole-corpus run. This is not a new Attempt,
source repair, qualification, materialization or training result.
Native raster selection keeps front and first-failed-view evidence rather than
duplicating all eight views. The initial six-subject readback exceeded its128MiB
guard and failed closed; the guard remains unchanged after bounding that selection.
