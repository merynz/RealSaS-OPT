# Corpus370 V5 — all-slot, eight-view, owner-neutral Graphics edit census

**Status:** implementation + private hosted run request committed; **real V5 results not yet verified**. This is an experiment plan and source-bound code, not a measured V5 PASS or training authority. PR #327 remains draft.

## Why V5

V4 provided genuine source-vs-soup/no-op and editable A/B pair evidence on three SHA-exact subjects (Cat, Triceratops, Cowfish), at eight original camera views, with independent exact-byte replay. Its limitation was sampling **two selected operational slots out of eight** per subject, all in rest pose at 192×192. Source-hidden graphics were not lost in the anchor-pair test, but six other slots remained unmeasured individually.

The V5 all-slot test preserves the same immutable V5 observation index, original source/roster, original rest geometry, native visibility join and all-view geometry compiler proposal. The source-art and pixel data stay in private Drive; GitHub gets only code, run request and non-sensitive status descriptions. All source-face IDs and anonymous group IDs are teacher-only.

- `tools/corpus/court_corpus370_all_slot_eight_view_edit_v5.py`: separate full-field RGBA court, immutable slot enumeration, bounded source/soup and no-op parity, measured direct pixel consequence for every slot and an anchor pair's conditional reveal. - `.github/workflows/corpus370-hosted-all-slot-eight-view-edit-private-v5.yml`: three independent GitHub-hosted original-source workers, no WSL GPU dependency; exact private Drive source hydration, independent Blender 4.5.14 byte verification and private results transfer.

An individual worker plans `8 cameras × (3 baseline + 8 one-group removals + 1 paired-anchor removal) = 96` full-field renders; across three workers, **288 intended renders**, not a result claim.

## Admission and scientific interpretation

A successful research run must verify every source slot has a distinct, repeatable removal arm at every camera; exact source and proposal identities; eight bounded source/soup + no-op parity views; and the independently courted anchor B reveal after removing A. The number of slots with any visible direct effect is **reported separately**. An entirely occluded or offscreen slot may have zero direct pixels yet remain legitimate; that is `ABSTAIN` or `UNKNOWN`, never `DIFFERENT_DRAWABLE`.

This experiment **cannot** prove authored drawable identity, mechanical causality, full native-resolution CAA, skinned multi-pose persistence, materialization readiness or IRIS/TESSA training. It may reveal geometry-only grouping failures and false confidence from one chosen pair, but its own numeric group count is not an optimized puppet representation.
