## Why V6 was required

The preceding 8-camera, all-slot rest-pose V5 experiment independently measured **22 of 24** slots with direct full-frame removal consequences. CAT slot 7 and COWFISH slot 6 each had **zero** direct-pixel effects across all eight composite views. That is **not** evidence of no source surface, no useful layer, or different/same authored drawable. An anonymous source region can be entirely suppressed by other regions in the composite.

V6 retains the exact same original source bytes, original rest geometry and 8-view source cameras, all-view anonymous compiler group addresses, and source/soup/no-op pixel parity. For every slot it performs **two fundamentally different interventions**:
- **Direct removal:** compare original triangle-soup full composite with the same composite with this slot removed.
- **Full peel (isolated slot):** suppress **all** other anonymous source slots and compare the remaining original source material/UV/alpha render to the all-source-slots-removed baseline. Source-face ID is an oracle address, *not* an IRIS student label.

All eight original cameras are retained. For each of 3 subjects and 8 views there are 21 render arms: 3 baseline + 8 direct removals + 8 isolated slots + 1 clear-all + 1 two-slot anchor removal. This makes **504** original-source render arms in three private hosted workers, at 192×192, rest pose.

## Strict limits

1. All images were bounded **192×192 rest-pose** source renderings: no native-resolution CAA, animation-pose persistent editability, deformation, attachment or draw-order authority.
2. All original source faces, layer IDs and geometry are privileged teacher evidence only; no semantic category or owner truth has been exported as an IRIS loss target.
3. The **8-slot count is a proposal** generated by a geometry-and-kinematics compiler; this experiment proves no optimality, and visible source pixel contribution alone cannot determine an independently editable operational unit.
4. Source-native authored motion is observational; same motion does not prove SAME_DRAWABLE, differing deformation does not prove DIFFERENT_DRAWABLE. Neither result promotes a causal Response target.
5. No zero-effect slot may be silently discarded or classified DIFFERENT_DRAWABLE; no observed source-isolation effect may be used as automatic SAME_DRAWABLE either. Teacher-only slot observations remain typed.
