## Measurements and interpretation

The finest available existing geometry hypothesis (64 for CAT; 32 otherwise) is a **proxy reference**. No author drawable identity is inferred from it. Per source-target task and per candidate size:
- render original source, triangle soup, no-op, all-clear scene;
- remove reference fine group, isolate reference fine group;
- remove and isolate the source group containing exactly the same teacher-only face for each coarser candidate;
- compare **entire RGBA field of view**, across **every original camera**, against the fine edit and isolation reference;
- count extra altered pixels, direct visibility and isolated visibility; preserve absent target evidence as ABSTAIN;
- preserve group complexity as separate measured dimension, with no automated optimum, no draw-authority PASS and no training masks.

## Two critical limits

1. More granular groups will mechanically match the *finest chosen proxy* better because that candidate defines the reference. The coarse-vs-fine pixel delta is **source intervention capacity loss**, not true optimum or guaranteed improved puppet editability. Do not rank partition sizes by this metric alone.
2. Rest-view alpha edits cannot decide whether grouped source faces remain independent under skinned authored motion. Real pose persistence, attachments, seams, draw order, overlap, inverse controls and source-to-canonical target mapping are separate future gates.
