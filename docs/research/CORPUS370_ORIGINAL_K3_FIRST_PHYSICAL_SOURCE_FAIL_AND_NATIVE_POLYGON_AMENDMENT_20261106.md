## Pre-registered fidelity correction, no algorithmic promotion

The first source-isolation strategy built independent world-space triangle meshes from the evaluated Blender FBX loop-triangles. That is source-face equivalent, but **not necessarily Cycles raster/sample equivalent** to the original raw-source polygon/quad geometry at subpixel boundaries. A single imported quad diagonal or numeric/source-object/BVH difference can change whether a source sample hits geometry; precise cause is UNKNOWN without source-ray sample trace.

**Next candidate implementation:** clone original imported FBX mesh objects with their original local-space vertices, original raw polygons (including quads), original world transforms and rest rig/modifiers, and physically remove nonselected raw faces by their original constant material slot. This preserves source polygon triangulation geometry source as closely as possible. Independently compare the same exact original source V18a canonical evaluated triangle palette census (all 1334 faces map once) before any rendering. If original imported polygon contains mixed-color triangulated faces, that polygon is UNSUPPORTED/FAIL rather than heuristically split.

No changes to 13 arms, source colors, RGB edit rule, cameras, Cycles subset indices, resolution, thresholds, authority flags. Every original source sample must be scored again, and source FULL vs physical isolates is a separate hard gate, not merged into a compositor PASS.

This is a source representation/sampling fidelity experiment, not an artist drawable segmentation or training result. Any remaining mismatch is FAIL and recorded, not filtered as a boundary sample.
