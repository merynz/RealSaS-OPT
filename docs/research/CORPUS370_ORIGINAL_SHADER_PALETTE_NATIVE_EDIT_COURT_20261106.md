## What is and is not proven

**Proven here:** original-face SHA/source-world binding to exact original shader policy; reimport-independent per-face constant palette classification; all unsupported shader faces UNKNOWN; mathematically exact workload common refinement; qualitative/quantitative source V18a baseline under an explicit edit-control workload.

**Not proven:** source physical renderer tint edit consequence or absence of collateral appearance edits; arbitrary texture palette decomposition; 2D drawer/artist ownership; secondary motion, attachment, collision, occlusion, draw order, hidden surface completions, unseen-morphology genericity, privileged-source-to-one-view student observability. The 257 atom count is a representation-class policy consequence, not a scientific segmentation gold label.

Truth matrix impact: qualified **source constant palette observations** can be recorded separately from ray visibility and owner/affinity targets. Artist same-drawable/different-drawable supervision count remains 0. All owner, IRIS/TESSA, materialization and training authority flags remain FALSE.
