## Scope: existing Graphics Evidence IR v1 complemented, not replaced

The original Generic Graphics Evidence IR v1 already keeps source-private V18j geometric rays, local depth/visibility and UNKNOWN owner labels from a sparse, retrospective source sample. That source evidence is pose2 and uses a fixed ray grid which is NOT exact stochastic Cycles pixel sampling.

The new companion ledger consumes the separately independently courted K3 original Triceratops physical color-edit evidence. It represents REST-pose, V1/V3/V5/V7, same-Cycles-sample source material and 3 independent physical edit operations, at **per-view and per-operation aggregate granularity**. It never silently joins V18j pose2 rays with rest-pose K3 pixels, and it does not store or claim qualified individual original-source pixel masks or continuous geometry-owner graph edges. The full source arrays remain private.

Source inputs and their SHA addresses are bound to the independent original K3 court and independent original native control court. Existing canonical CORPUS_TRUTH_AUTHORITY_CONTRACT_V1.json families are reused; not a new architecture.
