## How the independent court judges the source

- Source provenance: exact V5 private SHA lineage, existing V9 original animated source pose teacher, original source face ordering, V11 precommitted source query group hypothesis, and V12 native RGB-alpha edit provenance. V13 also remains an immutable prior source-only mechanics result.
- Mechanical intervention: imported original source action owner; perturb one source-local basis transform per controlled bone or native object, on original frame and source evaluated mesh; verify original source face/vertex identity and no-op restoration.
- Controls: perturb three axes and both ±5° signs. An independent null/no-op restoration check and an **analytic global root translation sham** protect against classifying all-moving regions as independent local deformation. This is NOT a real perturbed source root render.
- Independent mathematical classification: compare each original source mesh response with baseline source pose. A source-relative displacement threshold detects no-effect; best-fitting global SE(3) residue differentiates globally rigid-like from nonrigid local response. Rigless and FBX assets follow the same numeric court. On imported shape-key-only owner types not yet instrumented, record typed unsupported/UNKNOWN instead of manufacturing an actuator.
- Candidate anonymous geometry K8/16/32/64: a mixed candidate group under source control is a diagnostic **structural counterexample**, not an artist part split. Smaller mixed-group fractions at higher K show resolution dependence, not an optimal group count.
- Never mint source bone, node, mesh, material or action names as artist drawable or training ground truth.

## Crucial limits before teaching IRIS/TESSA

V13b has **proved true original source mechanical response instrumentation for these three sources across different source authoring systems**, not generic unseen drawable ownership, source shape-key full support, native full-resolution CAA or product editability. Per-source rig controls are a privileged training-source instrument; an input image does not contain those controls.

V12 rendered exact original RGBA full/source/group edits under original source authored poses; V13b measured real vertex perturbations under original source controls. **It has NOT rendered corresponding original RGBA/draw-order/alpha under the same ±5° V13b control perturbations.** Therefore V12 + V13b cannot yet be declared a joined owner/edit proof.

Mechanical factors and art drawables are distinct: a cape may be one drawable spanning several mechanical modes; two separately editable overlays can move identically. Neither shared response nor different response alone is SAME_DRAWABLE or DIFFERENT_DRAWABLE. No source-mesh/bone name, material class, input subject taxonomy, fixed layer count or semantic prior is authorized as ownership.
