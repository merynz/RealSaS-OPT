The independent Python court **does not import Blender or source rig semantics**. It verifies all original V14 parent source/teacher/private manifest hashes, original native V13b ±5° vertex arrays, 48 new joint source-world vertex arrays, all original action freeze and source-vertex before/after facts, original-source vs soup image parity, same original baseline as V14, full/isolated effect masks and 4-camera invariance of the original joint mesh pose.
