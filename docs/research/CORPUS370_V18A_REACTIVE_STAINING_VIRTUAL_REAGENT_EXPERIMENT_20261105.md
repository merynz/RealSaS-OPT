# Corpus370 V18a — Reactive Staining / Virtual Reagents (precommitted)

**Scientific status: candidate experiment, NOT actual drawable truth until independent source editor edit-collateral court.**

## Hypothesis
Apply many controlled, mechanically distinct *virtual reagents* to an unknown original character. Instead of asking whether a surface is “hair/body/arm”, measure how each **anonymous original-source surface** responds to independently actuated control probes across authored poses. Paint a transient diagnostic pseudo-color on source faces based on their response fingerprint. Predict an unconstrained number of connected graphics layer candidates with precommitted source adjacency and motion-signature similarity thresholds. Restore original alpha/RGBA; never make diagnostic colors part of source artwork or student input.

This is a direct continuation of V7/V12 source-face edit hypotheses, V13b mechanically authoritative native control interventions, V14 verified source→RGBA transport, V15 measured isolated-vs-whole image effects, V16 real nonlinear simultaneous controls, and V17/V17b true posed source ray/subpixel evidence. It does not redo the completed geometry truth or substitute 2D flat-image segmentation.

## Method

1. **Original SHA source custody:** reopen exact source world vertices, rest faces, V13b original ±5° native control arrays, V16 true A+B world vertices, V14 precommitted blind controls and original V17 source rays/court; no identity/material/action labels allowed to reach the prediction.
2. **Probe selection:** greedily choose **up to 12 anonymous control axes** using only baseline **pose 0 geometry and geometric response support**. If a source has fewer, report the actual number; never pad with invented controls. An exact V14 original source precommit determines the 2-control simultaneous A+B interaction that contributes a separate geometric channel. No artist target count.
3. **Virtual stain signal:** signed 3D motion vectors, normalized local/nonrigid residual after Kabsch global rigid fit, movement magnitude and actual nonlinear V16 joint A+B response. **Only original authored poses 0 and 1 enter the fingerprint and the connected-component proposal.**
4. **Propose multiple variable-K partitions:** source triangles sharing genuine original mesh **edges** (never merely a vertex, and abstain on nonmanifold 3+ edges) can fuse when their normalized multi-channel responses agree within frozen thresholds **0.045/0.10/0.18**. All faces remain addressable. There is no preset part count, semantic slot, human drawable layer label or “best K” based on the hidden result. Three candidate policies preserve a fidelity-vs-fragmentation frontier.
5. **Heldout test:** original authored **pose 2** is never used to select probes, derive features, normalize channels or cluster faces; independently measure its real V13b source per-face motion within each candidate group, alongside candidate counts/singleton penalties. The original V17 source pose2 RGBA and posed ray observations are **diagnostic only after candidates are fixed**; they cannot promote artist identity.
6. **Private preview:** render original RGBA next to a source-geometry painter-color view at heldout pose2/source camera 0, stored in private Drive **only**. It is explicitly *not* a physically correct alpha compositor or Studio final puppet. Source art and all source-face label arrays never leave private origin.
7. **Independent source court:** separately reopen all exact source bytes/SHAs, reconstruct face adjacency, selected probe geometry, fingerprint, graph components; verify each component connected, 3/3 frozen thresholds, real source heldout pose 2 motion loss, original V17 image-ray observation counts and zero training/artist authority. Rejection of forged source SHA, part-count, heldout leakage or false owner/pass is fail-closed.

## Acceptance / what remains unknown

For each source, **source SHA / pose split / effect fingerprints / multiple connected groups / heldout mechanical consistency / private full chain court** must pass. No threshold may be selected after viewing pose2 outcomes and then marketed as unseen success.
