## Hypothesis and what is truly measured

V18a assigns original source triangles a *virtual chemical reagent response fingerprint*: signed mechanical response under different native source controls, local rigid-residual deformation, and true V16 simultaneous A+B nonlinear source movement. Up to 12 probes selected from original pose0 source geometry only. Stain groups are connected source-face regions from frozen color-independent similarity thresholds 0.045, 0.10, 0.18. They are **not human original authored drawables**, nor guaranteed editable. Original source material/UV/full RGBA is untouched.

V18b supplies the necessary falsifier. At ORIGINAL authored source pose2, deliberately excluded from V18a fit, it physically renders the character under 4 original calibrated cameras in Blender 4.5.14:
- original fully animated source, original UV/material-preserving posed source-face soup, source no-op, clear soup;
- one original-source face hidden / isolated for each of six externally precommitted **V11 original source-face heldout loci** (V11 target indices 0,2,4,6,8,10, chosen before V18a used any of these source edits);
- original V18a stained candidate group hidden / isolated at each of three precommitted thresholds for the same six locked source-face targets.

Therefore each view has **52 actual Blender render arms** (4 + 6×2×4), total 208 per original source. No source RGBA edit effect is fabricated by subtracting individual A/B images. Every edit runs the original source material, UV and finite geometry at original authored pose2.

The independent court reopens exact V14 original source, V11 heldout target, V18a candidate report/NPZ/court and Blender result byte SHA; verifies actual source/soup/noop/empty parity and physically remeasures all 72 (3 candidate policies × 6 heldout target faces × 4 views) edit consequences. It distinguishes:
- \`GROUP_ONLY_COLLATERAL\`: source pixels affected when removing or isolating the whole group that were not affected by removing or isolating the locked single source-face target;
- \`TARGET_RESPONSE_NOT_REPLAYED\`: target face's reference effect absent from group edit;
- \`MASKED_OR_UNOBSERVABLE\`: original source target face edit has no visible consequence (true graphics owner is **UNKNOWN**, not a negative label);
- candidate complexity: V18a actual variable-K source region count and isolated/group face count.

**Important:** a single source triangle is the minimal edit *proxy*, NOT the artist's intended drawable or an optimal graphic component. A group that affects pixels outside this tiny proxy may be a legitimate larger artist layer; the court reports collateral quantitatively, not as artist-truth failure. Source alpha/texture seams, source visibility and split complexity remain separate goals; only an independently heldout real artifact behavior plus evidence-typed UNKNOWN can inform an eventual operational graphics-owner target. No learnt model/IRIS/TESSA/materialization gate PASS is possible from this pilot alone.
