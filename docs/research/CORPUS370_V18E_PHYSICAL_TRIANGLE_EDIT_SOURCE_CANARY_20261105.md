## V18e research question

Can we independently reproduce exact original-source picture, no-op/empty and **physically real face REMOVE/ISOLATE** at the original unseen authored pose2 without dependence on Cycles transparent-ray depth?

V18e uses *genuine geometry deletion*: duplicate each original posed, UV/material-preserving Blender triangle-soup mesh, delete explicitly excluded source triangles via BMesh FACES removal, and bind the resulting real reduced mesh for each render arm. When all triangles of a soup object are excluded, hide the entire object from render; when no triangles are excluded, restore its untouched original posed source-soup mesh. Restore from the **same exact base source mesh** on every arm, never accumulating edits and never replacing source 3D teacher evidence. No source artist part names are target labels.

**Frozen tiny canary** on original SHA-locked Cat and Triceratops only, four original cameras 0/2/4/6, pose2, original 192×192/32 Cycles samples, 8 real Blender arms/view (32 frames/subject):
- SOURCE_ORIGINAL (actual imported and animated raw-source model)
- SOUP_FULL, SOUP_NOOP, SOUP_EMPTY (actual physically present/absent geometry)
- SINGLE_FACE_REMOVE_T00, SINGLE_FACE_ISOLATE_T00 (historical preregistered V11 source target 0; no opportunistic reselection after observing edit effects)
- STAIN_REMOVE_0p1_T00, STAIN_ISOLATE_0p1_T00 (V18a frozen .1 candidate group containing that source triangle)

The original V18a array still contains ALL three threshold proposals; this canary selects .1 for bounded mechanism validation only, **not** because .1 optimizes edit results. It does not score which threshold is best.
