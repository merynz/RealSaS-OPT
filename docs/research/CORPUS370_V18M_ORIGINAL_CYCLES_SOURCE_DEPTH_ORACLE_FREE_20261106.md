### Fixed gates

- Original same-offset depth arm coverage alpha must match corresponding original V18l G/R color arm exactly within `1e-6`; otherwise FAIL for source sampling drift. No swapping or mask correction.
- 1-spp layer coverage must be binary; nonbinary coverage is a FAIL/UNKNOWN, never negative relation.
- All original measured source depth values must be finite and in the normalized range `.019–.981`; outside is UNKNOWN.
- When G and R both cover the same source sample, nearest by depth. `|depth_G-depth_R|<=.0002` is **UNKNOWN depth tie**, not a forced layer order or loss-positive/negative.
- If one layer covers sample, that layer is visible; if no source layer covers, transparent pixel sample. UNKNOWN sample is excluded from scoring; if any of eight source samples for a pixel are UNKNOWN, its eight-sample aggregate is UNKNOWN.
- Diagnostic source material always original physical triangle geometry, fixed two-color emission, not original texture/CAA.
- Score (a) **each qualified original Cycles sample** for RGBA/alpha mismatch, (b) all fully qualified eight-sample image pixels and camera partitions separately, including source baseline previously passing pixels, (c) rest of pixels as explicit UNKNOWN. Report gains **and** regressions versus fixed sample-first and postfiltered G/R OVER.
- Critically: **wrong individual sample orders can perfectly cancel in the eight-sample mean** (e.g. reversing 4 G and 4 R ray colors). Therefore per-sample oracle-free error is a necessary independent guard; aggregate source pixel parity alone is insufficient.
- No success promotion if the predicted frontmost source face is chosen by closeness to FULL RGB/alpha instead of independent original source View Z geometry. No total global draw order claim; order is local to source pose/view/pixel/sample.
