## Frozen research question

V18q had independently courted source multi-axis response evidence and bounded *unaccepted* lifted proposals:
- CAT: source 260 topological islands, 288 pooled V18a groups; 1,150 nonlocal island pairs retrieved **only by mean response similarity**.
- TRICERATOPS: one topological island, 22 pooled V18a groups; the axis-OR cut stress test produced 422 fragments with 291 singletons.

V18r tests whether Cat's proposed cross-island pairs are spatially close in original 3D and whether the source geometry itself exposes stable local creases on Triceratops. **Neither 3D proximity nor face normal angle equals a source artist drawable boundary.** These features were absent from V18a and V18q graph arrays; source 3D geometry is a new, independently SHA-bound teacher source of evidence, not guessed coordinates.

## Methods preregistered in the code

1. Original source-world triangle normals are independently recomputed from the three actual authored source vertex arrays for every original source face index. Shared-source-vertex-edge local face pairs preserve all mechanical response evidence from V18q. For each of the two **fit** poses, a normal angle >=30° is a *normal-crease evidence diagnostic*, not a cannot-link or artist boundary. Evaluate its persistence in original authored pose2 **only in court**.
2. For source V18q's already-frozen 1,150 Cat cross-island *retrieval candidates*, compute actual minimum **vertex-to-vertex** distance between source triangle vertices of both disconnected islands, divided by the original first-fit-pose source 3D AABB diagonal. This is **NOT exact triangle-to-triangle surface distance**, UV chart continuity or renderer appearance evidence. Independently report two-fit-pose gaps and heldout pose2 gap. Sensitivity thresholds `0.005,0.02,0.05` of source extent are diagnostics only; even coincident vertices cannot mint a SAME_DRAWABLE.
3. Heldout original pose2 is never used to choose the graph, its original source axes or proposed cross-island pairs. No source-private material, source UV, ray occlusion or native appearance edit outcome is passed to this candidate compiler. All such fields explicitly remain **UNOBSERVED**.
4. Recompute every output in a separate independent source court from exact parent original SHA-pinned arrays; reject a forged source pose, a fake source UV claim, a changed graph edge, a fabricated exact triangle distance, a positive artist owner relation and any training authority flag.

## Measured original-source results

### Cat — 1,150 mechanically proximate lifted retrieval candidates

| Original source fit+heldout geometry predicate | Fit original poses 0 AND 1 | Same candidate also near in heldout authored pose2 |
| --- | ---: | ---: |
| Source minimum vertex gap / extent <=0.005 | **497** | **497** |
| Source minimum vertex gap / extent <=0.02 | **547** | **547** |
| Source minimum vertex gap / extent <=0.05 | **777** | **777** |

There were **zero** fit-near candidates that failed the corresponding heldout proximity test at these thresholds. This may reflect original mesh source islands that are persistently adjacent, duplicated seam vertices or multiple planes sampled together. It does NOT establish they belong to the same artist drawable. Nor does it license an automatic source topological merge. Importantly, original source V18q's nonlocal retrieval was *response-only*, not selected from heldout spatial closeness.

CAT local face normal angle >=30° on both fit poses: **2/424** shared-edge face pairs, **2/2** remain above this angle on heldout authored pose2; 0 of the two overlaps with pooled or any-axis response-divergent local edges. Most CAT's graph difficulty remains its ~260 original disconnected face topology islands.

### Triceratops — single connected source, strong crease/axis contrast

- Original source local shared-edge face pairs: **2,001**.
- Original source normal-angle >=30° in **both fit poses**: **667**.
- Those 667 fit-consistent normal-crease pairs also >=30° in original heldout source pose2: **652**.
- Of the fit-consistent 667 creases, **226** overlap with original mechanical any-axis divergence; only **15** overlap with original all-channel pooled-RMS divergence under the same frozen `.10` mechanical threshold.
- Original V18q nonlocal cross-topology-island pairs: 0, because this original source has only one source topological island. No lifted merge metric can be claimed here.

This is a strong diagnostic signal that **separate multi-axis responses and 3D shape geometry select different sets of original face relationships**. But original face normals may reflect triangulation, polygon tessellation and winding; some angles can mark natural within-drawable creases. A crease is not a new editor component gold label, even when it persists across views or poses.

## What is independently proved and what is missing

**Proved:** exact original source V13b authored pose-array geometry can join original V18a multi-axis response and V18q typed affinity graph by real source SHA/rest/pose provenance; a source 3D proximity screen can narrow cross-island Cat hypotheses without viewing heldout edited images; and local source Triceratops face-normal creases provide orthogonal 3D shape evidence, supporting more targeted future tests.

**Not proved:** true triangle surface minimum distance, screen-space material appearance, UV continuity, nonbinary alpha, independent original artist layer identity, actual editor-friendly K, source heldout independent edit consequences for the NEW V18r group candidates, or unseen IRIS inference.

Real-source **source V18r court 3/3 PASS** is **NOT** `GRAPHICS_OWNER_PASS`. Every authority remains `graphics_owner_authorized=false`, `iris_training_authorized=false`, `tessa_training_authorized=false`, `materialization_authorized=false`, `training_authorized=false`.
