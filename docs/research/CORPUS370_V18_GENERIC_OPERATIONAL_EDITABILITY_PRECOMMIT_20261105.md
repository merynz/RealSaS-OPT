# Corpus370 V18 precommit — generic *operational* editability, not copied artist semantics

Date: 2026-11-05. **Experiment proposal only; not a real result or training authority.** The source pilot is V7/V12's independently heldout native **edit consequences**, V13b–V16's actual native mechanical responses and nonlinear A+B source RGBA, V17's posed original geometric ray/Barycentric↔pixel join, and V17b's frozen physical subpixel support for initially unknown pixel-centre rays.

## Truth definition

A human original drawable identity is generally **not uniquely recoverable from a single source raster**. Even independently visible source faces may have been authored in the same editable layer, and co-moving geometry or a common native rig/action does not mean the same artist graphic object. The generic product must instead learn an **operationally editable representation**: anonymous source graphic components stable in source 3D addressing, pose and camera, whose edits replay source appearance with independently bounded collateral. Truth is an **observed relation or ABSTAIN**, never a fabricated body/hair/arm label or forced K.

The learning target is an evidence graph, not fixed semantic segmentation. Separate node/edge families:
- `SurfaceLocus`: original source triangle, barycentric address, UV/local chart, source depth geometry; does not identify owner.
- `MechanicalResponse`: signed actual source-native Δ3D over time, local vs rigid vs noop, independent A/B and nonlinear A+B residual; native controls are private teacher query handles only.
- `GraphicsPresentation`: actual original UV/material/RGBA contribution, alpha/reveal, ordered hits and compositor visibility with source-camera/pose coordinate binding; no source face is declared opaque based solely on ray intersection.
- `OperationalGraphicEdit`: hide/isolate/recolor/translate native source-face candidate as one edit intent and quantify matching full-scene and isolated source effect at unchanged pose/camera; visibility UNKNOWN for aliased or masked candidates.
- `EditRelation`: two *candidate edits* independently replaying heldout source art with quantified collateral, not an artist SAME/DIF label. Human intended grouping remains optional independent gold benchmark, never derived from mesh parts.
- `SourceIdentity`: permutation-invariant anonymous slot/charts tracked across poses; original action names or material names forbidden in student inputs.

## Real competing hypotheses, no preferred fixed K

The proposed court must compare all methods on identical original heldout targets:
1. single entire source graphic;
2. original geometry connected components;
3. UV/appearance chart boundaries (teacher-visible source UV is evidence, not an artist owner label);
4. V7/V12 geometry-only anonymous 8/16/32/64 candidate group *hypotheses* (never treating finest group as gold);
5. source face-level trivial proposal as an editability upper-bound with explicit complexity/overfragmentation penalty;
6. causal mechanical-response graph grouping, including V16 **joint** nonadditive interactions but no co-motion owner promotion;
7. edit-consequence-constrained proposal from blind source-only evidence.

A group is operationally useful only when independent **edit locality**, heldout pose/view consistency, appearance preservation, source alpha and geometry, and scene assembly constraints pass. The court must report a **Pareto frontier** (collateral vs number of independently addressable components vs appearance seam/alpha error); there may be no single universally correct K. Underidentified semantics or masked edit result means UNKNOWN, not wrong/negative.

## Split and independent controls

Precommit candidate geometry/source-only proposals before reading any future original edited raster. Select heldout source face target families and original authored poses/view **independently of outcome images**, including hidden and reveal-only source contributors. Use source no-op, camera-root sham, independent A/B source control, simultaneous A+B original action, source-versus-original UV/material preserving soup parity, recolor preserving alpha, hide/isolation with typed source face mask, and source identity/canonical address. Recompute independent original Blender results on multiple morphologies and unrelated creators, not only Cat/Triceratops/Cowfish.

Qualify separate:
- source art pixel fidelity (CAA, alpha, depth seam);
- valid original geometric source face-to-pixel ray match and subpixel coverage;
- ordered alpha-composited contributor evidence (must be explicitly measured, never inferred from geometric front face alone);
- genuine mechanical deformation source identity and influence;
- operational edit-response repeatability and collateral;
- unobserved/revealed masks, scene geometry and material licensing;
- lineage-safe per-family per-head learner payload.

**Blocked until real courts:** true original artist-layer SAME/DIF, full source 2D graphics ownership, IRIS/TESSA loss training target, complete product puppet and Materialization Run All. Record PASS and N/A/UNKNOWN separately for each original source subject and family; do not require all 370 candidates to have authored animation if an original source legitimately lacks motion.

This precommit is an engineering test contract, not a promise that an image-only encoder can infer human art intent on intrinsically ambiguous objects.
