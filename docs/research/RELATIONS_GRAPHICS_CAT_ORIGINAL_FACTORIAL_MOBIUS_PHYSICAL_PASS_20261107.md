## Mathematical theorem — invertibility of full Boolean factorial

For every fixed same-source physical observation address \(x=(source,pose,view,sample,pixel)\), let \(Y_x(S)\in\mathbb R^4\) be the source physically measured premultiplied RGBA for independently applied edit subset \(S\subseteq\{0,1,2\}\).

Define the **unique exact** Möbius interaction component

\[
\Delta_x(A)=\sum_{B\subseteq A}(-1)^{|A\setminus B|}Y_x(B).
\]

Then the full physical source edit table is recovered for every \(S\) exactly:

\[
Y_x(S)=\sum_{A\subseteq S}\Delta_x(A).
\]

**Proof:** Swap finite sums. For each \(Y_x(B)\), the resulting coefficient is
\(\sum_{A:B\subseteq A\subseteq S}(-1)^{|A|-|B|}=(1-1)^{|S\setminus B|}\), equal to one iff \(B=S\) and zero otherwise. Thus inversion is an identity. As the transform matrix is triangular with diagonal one, the decomposition is unique for each source measurement address in the full experiment. QED.

This does not assume additive source appearance edits: it MEASURES any nonlinear interaction at order two or three. It is conditioned on the **chosen source edit basis**, not uniquely chosen author art parts. For a subset \(A\), only the original physically observed values for all \(B\subseteq A\) are needed to identify \(\Delta(A)\); unmeasured higher subsets remain UNKNOWN, enabling targeted larger-operation experiments without a forced all-\(2^m\) run.
