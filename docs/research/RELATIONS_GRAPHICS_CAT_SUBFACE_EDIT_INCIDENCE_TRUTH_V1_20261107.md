## Mathematical counterexample to an indivisible face-level Boolean edit-response label

Fix one original triangle f, original pose p, source camera v and source Cycles sample policy. Suppose two distinct pixels q0 and q1 each have independently qualified entire-pixel first-hit source face f, and original source UV addresses inside two **disjoint**, independently edited atlas rectangles R0 and R1.

Let d_k(q) be the independently observed original source BASE versus SINGLE-k change in premultiplied linear RGBA at the exact matched source Cycles sample. Assume original V2 court proves at EVERY stored sample of both pixels:

\[
\|d_0(q_0)\|_\infty>0.025,\quad \|d_1(q_0)\|_\infty\le0.025,
\qquad
\|d_0(q_1)\|_\infty\le0.025,\quad \|d_1(q_1)\|_\infty>0.025.
\]

A uniform face-level *observed edit-response* function B(f,k) would have to assign the same Boolean response to operation k at every pixel of f. Yet operation 0 requires B(f,0)=1 at q0 and B(f,0)=0 at q1, a contradiction. Likewise operation 1. Therefore **a uniform face-level binary effect label cannot represent these original measured edit outcomes in the specified physical sample/tolerance domain**.

This conclusion is about the *model class* of uniform Boolean face edit response. It does NOT prove that the actual source triangle must be split into two drawables, does NOT identify an artist layer, and does NOT preclude one source graphical carrier having multiple internal texel masks or control subaddresses. Nor does it claim that zero measured pixel effect implies nonparticipation of the edited source material in other pixels, channels or poses. Only the exact physically source-courted per-pixel positive/negative data are qualified.

A correct source Graphics record may therefore need an address such as:

    (source_SHA, original_face_ID, barycentric_or_UV_subaddress,
     original_pose, source_camera, exact_sample_policy,
     original_edit_operation, observed_PM_RGBA_effect,
     visibility_first_hit_proof, validity_mask, independent_court_SHA)

This is *fine-grained SOURCE evidence*, not a mandated runtime decomposition or IRIS supervised target.
