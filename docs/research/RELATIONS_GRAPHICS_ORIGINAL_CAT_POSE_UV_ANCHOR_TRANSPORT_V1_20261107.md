2026-11-07. Research source truth only, stacked on Relations×Graphics PR #369. Product intent is an editable, persistent puppet whose image-linked appearance controls survive source deformation. No main, model head, student training or materialization changes.

## Parent audit

Original Cat V18u (#369) physically linked source face IDs to real REST Cycles UV consequences but did not measure simultaneous FIT-pose mechanics and edit consequences. Source V3 (#355) independently observed 64 physical Cycles texture edit renders at native authored teacher pose 0 and pose 14; four original source cameras V0/V2/V4/V6, Cycles sample indices 0 and 16, original BASE + 3 source UV RGB-invert edit operations. Original V3 physically refuted the restricted frozen screen-space edit-delta class, but could not identify which original face/UV subaddress produced an individual physical source edit pixel.

This work binds existing V3 source physical samples to original 684 indexed Cat faces, exact original GLTF face-corner UV and actual per-pose native teacher XYZ. All original evidence parent bytes must match immutable SHA receipts (GLB linked via admitted V3, teacher, UV, camera, 3 independent atlas edits, original V3 samples and independent court, plus V18u court). No additional Blender images are generated or source-image thresholds adjusted.

## Falsifiable source geometry/UV/physical evidence

For each original source face, pose and camera, qualify only pixel squares with 0.05 px guard whose entire area lies strictly inside the projected face and original clip limits. Require strict 1e-5 depth dominance over **every possible other original triangle** on their exact convex projected intersections with the square; barycentric source UV at all four guarded pixel corners must lie at least one texel inside one original atlas edit tile. These conditions imply all camera rays within the guarded pixel have the same original source first-hit face and source UV edit region under the frozen orthographic opaque-source regime.

Require both original V3 Cycles sample offsets physically show BASE→SINGLE-k premultiplied RGBA change greater than inherited 0.025 tolerance at that source pixel, no other independent SINGLE edit changes it above tolerance, and original source alpha remains opaque.

For a qualified source pose0 pixel center, obtain its **original face barycentric coordinate**; project that same source barycentric point of the same original face under pose14. If the target lands inside an independently geometrically and physically qualified pose14 edited pixel for the same face, source camera and edit operation, this is a qualified **source-UV anchor pose transport** witness.

It is **NOT** proof that the stochastic Cycles ray at either pose fell on the exact same subtexel, nor does it assert equal RGBA sample deltas at one texel. It proves that one source face/UV material anchor is geometrically transported, and the surrounding full pixels in both posed physical renders show the intended independently controlled source edit.

## Scope and evidence discipline

Original geometry was sampled at native teacher ordinals 0 and 14 only (source maximum vertex movement 0.2230362676971853). Missing full-pixel evidence at a pose or camera is UNKNOWN, not a real hide/reveal event, absence of material, artist drawable boundary or cannot-link. Face+edit IDs at two poses are necessary but not sufficient; the actual barycentric anchor must land within another qualified physical source edited pixel.

## Source evidence, capability, policy

- **E, source truth:** observed original face/UV addressability, pose-specific first hit, real original physically edited pixels and qualified geometry transport between two source authored poses.
