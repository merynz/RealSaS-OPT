# RSS.vNext — Output × Loss × Source Truth × Preparation Audit

**Pre-training gate, 16 November 2026.** This is a code-grounded contract audit, NOT a declaration that any real corpus, GPU or unseen product acceptance passed.

## Contract and scope

A model output is only trainable through a qualified loss. A declared loss needs the exact teacher tensor, independent source lineage, valid masks and a permitted phase optimizer. A source file *containing* joints/UV/animations does not imply these teachers are admitted. The JSON inventory includes exact trainer result-field names, eligible-source counters and original default weights, checked against source code. It is the machine-readable source of this matrix: [models/rss_vnext/training_supervision_inventory_v1.json](../../models/rss_vnext/training_supervision_inventory_v1.json). Test coverage compares every structural/SLRM weight directly with the source code.

The **same** persistent IRIS H(x) is shared across Geometry, Semantic and Graphics; TESSA owns the canonical editable control mesh/topology; AXIS owns rig/constraint proposals; MIRA owns decoded skin; Compiler resolves provenance and emits an editable Puppet; native Graphics owns final 2D appearance, including unknown/occlusion/alpha/drawable order. Source render/rig/mesh truth must not enter product inference as privileged evidence.

### Code and corpus status, kept separate

- **Implemented in code**: function exists and its input/target/mask is defined; this is NOT proof the full source dataset can provide it.
- **Default weight**: a positive number means an objective is configured by default, not that a qualified batch exists or a backward pass can occur. Missing targets may be omitted, and a strict production phase must require source-qualified coverage.
- **Foundry candidate**: R2.17A has inspected native GLB/glTF metadata; actual rights, topology semantics, canonical rest, triangle reindex, pose LBS and renders require independent qualification.
- **Real training ready**: source and mask receipt bytes verified; correct phase/optimizer; gradient reachability/throughput and held-out tests performed. None of those has been established for the entire real corpus by this audit.

## 7. Identity and loss routing gates before A100

Required join keys (some live in separate verified receipts; this list is a proposed *cross-family* release gate, not a claim every dataset row already carries these fields): **source_asset_lineage_sha256, dedup_family_sha256, dataset_manifest_sha256, original observations' SHA, canonical transform/coordinate ABI, 3D source mesh/face identity, TESSA token digest, AXIS joint order and rig digest, MIRA codec hash, source pose/mask SHA and renderer/camera/role schema digests**. All labels must map to the *same* 3D source, not just have individually valid hashes.

Training checks: **(1)** source/target/mask coverage counts per objective; **(2)** source teacher receipts keyed to exact tensors; **(3)** phase-specific permitted parameter owners; **(4)** mandatory head gradient reachability; **(5)** weighted loss gradient conflict diagnostic; **(6)** dropout/AMP/optimizer phase checkpoints; **(7)** held-out family separation and unseen teacher-free geometry/rig/skin/render quality.

## 8. Explicit unresolved preflight decisions

1. No GPU/A100 run has validated the source-rendered 20+ loss composite at product-scale 100x100x150 / higher sparse extraction, or established that all phase losses can be simultaneously active. Phase curriculum remains to be chosen from real per-family qualified counts, not an all-weights-sum default.
2. Default direct IRIS source backbone DINOv2 requires image H/W divisible by 14; the product neural bundle defaults to 512 and requires multiples of eight. **The same preprocessing ABI must be pinned for Stage A, Stage B and real two-image inference before production training.**
3. StdGEN++ paper favors localized high-frequency branch and coarse-to-fine 256x256x384 sparse FlexiCubes. Existing extractor supports chunked dense grid queries with 1.5M cube cap and axis <=256. Do not confuse config scaling with implementation of sparse active-cell extraction.
4. Inference Graphics retains unknown/occlusion semantics, but there is no verified independent generative editable hidden-layer texture/Drawable objective. Do not equate source first-hit RGB with full 2D Presentation.
5. Source-native rest-pose, source-specific face/rig alignment, and motion metadata must be independently verified; do not assume an animation presence flag implies LBS-valid posed consequence.
