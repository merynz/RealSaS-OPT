## What must happen to get 8K+ **real truth per head**

1. **Acquire source-original evidence, not just metadata** by prioritized licensed/attribution-checked, character/non-bipedal/stylized filter; preserve independent lineage and holdouts, rehash source bytes and per-asset dependency inventory.
2. **Deep physical stage**: native hierarchy, transforms, canonical rest/pose/camera, UV/textures/alpha, mesh connected and open manifolds, bone bind/skin/controllers/IK/driver/animation and explicit source import parity.
3. **IRIS Geometry / TESSA / AXIS / MIRA independent teachers**: source-bound geometry/SDF-sign-if-solid, topology/chart/motion correspondence, control reachability, skin/deform positives AND negative consequences, per-target fit courts.
4. **IRIS Semantic source-part teacher**: consume both the Core370/Master modular sources and actual PartVerse face maps; preserve face-to-original mesh lineage; generic morphological ontology with reviewed concept+instance+UNKNOWN; create same-source FULL/KEEP/HIDE/ISOLATE and independently validate original occluded surfaces, semantic 3D masks and camera pixel ID parity. StdGEN++ is a truth-builder reference, not a preexisting semantic PASS.
5. **IRIS Graphics independent presentation teacher**: original native RGBA/texture from source, separately source-qualified 2D stylized shader render, source-to-art appearance authority, global visibility, reveal/compositing, atlas bleed and alpha courts. No processed PartVerse GLB becomes approved 2D art without textures and visual evaluation.
6. **Compiler evidence court**: control/edit consequences, shape/visibility independent drawable necessity (not PartVerse part count) and 45-degree/view-independent puppet behavior.
7. **Final lineage-safe six-head matrix promotion**: only count 8K after each head's necessary core targets and independent courts have truly passed on distinct FIT identity clusters. Other heads may still use incomplete sources with per-loss MASKED/UNKNOWN only.

**Hard policy:** No fabricated source SHA, semantic labels, false negative, drawable count, rights, body orientation, 2D art quality, true control or target PASS to satisfy a number. An inventory question is not a measured answer.
