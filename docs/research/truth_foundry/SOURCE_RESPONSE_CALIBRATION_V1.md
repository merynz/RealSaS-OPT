## The new measurement

The Blender adapter preserves the exact source rest triangulation and evaluates
every native pose-bone local XYZ rotation at both signs on a preregistered
calibration ladder. It records the complete evaluated source vertex response,
rest-to-pose-identity difference, shams before/after all actions and common-root
translation error. It preserves UVs, source weight inputs, material node inputs,
decoded image pixels and a packed source scene for the later renderer adapter.
These are privileged evaluator inputs. No owner/bone/material ID becomes a
student target or static observation input. Unsupported control kinds stay explicit.

The ladder is for measuring numerical and nonlinear response, not for selecting
a training target or asserting physical joint limits. The producer does not
infer contact, stiffness, support, force or a source artistic draw order. The
source weight bank still requires its own evaluator correspondence court. The
appearance sampler and renderer remain unqualified. Static calibration has no
fabricated dynamic timebase.

For measured local derivatives J_i and an explicitly declared action-measure
factor B, a consumer-neutral pair object is

`C_ab = (J_a B)(J_b B)^T`, with `Sigma = B B^T`.

It retains response magnitude and contains no control ID. Under a nonsingular
control reparameterization J'=J A, B'=A^-1 B, the object is unchanged. Duplicating
a control requires transporting the measure; keeping the old mass would change
the object. Root rotations transform the 3x3 tensor covariantly, reverse pairs
transpose, and the full block kernel is positive semidefinite. Missing excited
controls invalidate a pair without renormalizing. Those algebraic courts are
implemented independently; **B and final model-facing target/loss selection
remain unsealed**. Native correlated clips alone are not an isolated J.
