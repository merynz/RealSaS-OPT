# RSS.vNext / BUSTED — causal multi-chain PART teacher ABI

The final AXIS/MIRA architecture has ONE causal control program and ONE
canonical mesh M*. This is the typed **mechanical-part graph** contract;
it does not invent a second semantic ontology or independent rigger.

## Source-grounded training authority

`axis_mechanical_part_policy=EMIT_SOURCE_QUALIFIED_PART_GRAPH_V1` is
an explicit model checkpoint policy. The default
`DEFER_UNTIL_SOURCE_QUALIFIED_V1` emits UNKNOWN and does not assume all
branches attached to one root form a single part.

A trusted AXIS source row can activate the existing trainable
`pointer_c` head **only** when all of the following are source admitted:

- `mechanical_part_graph_status` =
  `QUALIFIED_SOURCE_NATIVE_MULTI_CHAIN_PART_PROGRAM`
- `mechanical_part_teacher_sequence_sha256` equals the EXACT AXIS causal
  program sequence (including parent joints, CHAIN events and source witness)
- `mechanical_part_not_bone_name_heuristic=True`
- valid `mechanical_part_source_evidence_sha256` (64 hex)
- source-qualified causal chain teacher and nonzero
  `product_axis_mira_weights.chain_skin`
- checkpoint policy
  `axis_mechanical_part_policy=EMIT_SOURCE_QUALIFIED_PART_GRAPH_V1`

The teacher must describe **joint-path overlap**, not merely named
WING/CAPE/SKIRT entities or surface segmentation. Parent-contiguous CHAIN
paths are still independently validated. `pointer_c=-1` means UNKNOWN;
nonnegative ordinals form a causal, contiguous mechanical-part namespace.
A chain can join an existing part only if its joint path actually overlaps
that part's previously admitted paths. A shared root may connect two
*distinct* parts; ambiguous shared joints remain UNKNOWN.

## Model → Compiler / Skin → runtime

1. AXIS learns CHAIN parent/joint addresses and mechanical PART memberships
   jointly with the same H(x) supplied to TESSA and MIRA.
2. Compiler validates event order, chain connectivity, source qualification,
   group address and canonical joint graph. No post-hoc name grouping.
3. MIRA receives exact part/group graph from the causal AXIS event stream.
   A branched wing can be one group without becoming a false linear chain;
   unknown/unclaimed joints retain explicit UNKNOWN identity.
4. **Physics is separate:** a PART/CHAIN, OPEN surface, or source rig name
   is not a pin or XPBD/material witness. Source-native pin/hem/host-only
   intervention and final M*→canonical transport must pass the independent
   `mechanics_source_qualified_surface_pin_v1` court (#620). The separate
   explicit runtime policy still controls XPBD activation.
5. **Graphics is separate:** learned mechanical grouping is not drawable
   partition, source RGB/alpha truth, occlusion authority or ProductProof.

## Handoff to the data conversation

Native authored multichain rigs can provide source-qualified causal chain
paths and source-verified PART membership. The student is not permitted to
receive bone-name heuristics or invented semantic labels as positive proof.
UNKNOWN is not a negative label. Where one native part has multiple
legal graph decompositions, the data compiler must preserve equivalence
or mark uncertainty rather than forcing one arbitrary ordinal.

If no independent native graph receipt exists, the training phase must
leave `pointer_c` unqualified and cannot enable the part-emission policy
by claiming a synthetic group as source evidence. Small regression tests
only verify grammar and gradient connectivity, not learned mesh/rig quality.

## Acceptance still required

The grammar/source-teacher gradient is not the final behavioral proof.
Release requires held-out branch-only, host-only and combined interventions,
the actual final M* skinned surface, correct independent wing/cape motion,
source 2D appearance and complete ProductProof. This document is an
architecture/teacher ABI, not a licensing or data-processing operation.
