# RSS.vNext hybrid SDF/UDF M* — inference and source-truth handoff

## Role and authority

Product input remains **two original images**. Six generated views are
construction hypotheses, not additional source observations. The model has one
IRIS H(x) carrier. A source-free predicted component-kind gate may propose one
**OPEN** region slot and extract its local UDF zero-sheet. The signed IRIS
shell and open UDF sheet join **before** TESSA, AXIS and MIRA.

A successful geometric proposal is **not** a source-qualified closed SDF,
garment identity, drawable, physically calibrated material or ProductRevision.
Release must independently qualify the candidate. Never manufacture the open
sheet by slicing a signed solid or sewing coincident garment/body vertices.

## Inference path added in #617

`RSSvNextUnifiedCharacterModel.propose_teacher_free(...,
hybrid_open_policy=ProductHybridOpenM0PolicyV1(...))`

- Available only with pinned generated-six-view construction and one signed
  FlexiCubes source-free extraction; calibrated research mode cannot opt in.
- Candidate OPEN slot is chosen only from predicted component-kind logits
  of `model.component_udf`. Uncertainty or an untrained head can ABSTAIN.
- Query `model.query_component_unsigned_distance` uses the exact same H and
  chosen learned slot; source meshes and correspondence labels never enter.
- Open UDF extraction preserves real boundary edges. Join uses one disjoint
  vertex/face/component/layer M0. TESSA may refine this exact M0, but there
  is no independently generated second mesh or post-skin remesh.
- AXIS and MIRA receive the **final identical M*** mesh/face memory. Their
  output remains neural proposals until Compiler qualification.
- Raw Shape CAS carries `tessa_seed_component_surface_kinds` and explicitly
  denies source/product authority. Mesh court checks closed-edge incidence
  for signed components, open degree-2 hem loops, component isolation,
  layer identity and existing TESSA parent/scene SHA addresses.

## What the data pipeline should ultimately provide (NOT built here)

1. Independently licensed native component inventory with a documented
   OPEN/CLOSED/UNKNOWN scope and explicit source provenance. Existing
   `SourceNativeComponentUDFFitV1` already trains per-component UDF and
   openness with permutation-invariant slot matching. Source component IDs
   must never become student slot indices.
2. Exact source **open surface** samples and/or source-native indexed
   triangles for each permitted open component, including real boundary
   loops, weld/tear semantics and uncertainty masks. Zero UDF alone does
   not certify topology or edit-cut borders.
3. A source-verified route from those native faces to the *same final*
   student M* address (`candidate_mstar_topology_address_sha256`), after
   signed/open join and any TESSA refinement. Reusing a signed-only
   source-face transport on a mixed surface is forbidden.
4. Source-qualified rig/skin/pose consequences on the completed combined
   M*, with explicit rigid-body, garment, pinned-contact and freely moving
   regions. Missing labels are UNKNOWN, not ZERO/NO_FACE.
5. Source appearance, occlusion, hidden appearance, drawables and composite
   order remain Graphics truth. Neither a role label nor an open boundary
   alone is a pixel/visibility certificate.

## Training limitation to close before product readiness

The existing seeded TESSA objective accepts signed-source truth. Its current
source-surface loss must **not** be applied naively to an open+closed mesh:
doing so may pull the valid garment toward signed-only body supervision.

The current component-UDF source-native objective can train the open field on
the same H, but that fact **does not prove** a joint combined-M* TESSA
topology/rig/skin loss. A separate source-qualified masked
signed/open combined-M* objective and exact face transport are required
before marking the hybrid training/release task complete. This document is
a strict handoff contract, not a synthetic dataset or release proof.
