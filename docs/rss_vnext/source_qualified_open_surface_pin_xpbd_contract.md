# BUSTED source-qualified OPEN pin → canonical XPBD compiler ABI

This architecture handoff defines an **optional** executable Mechanics
admission. It is deliberately independent of truth production, segmentation,
prediction, or a physics material oracle.

## Ownership distinction

- **Visual instance**: can include an open garment sheet with its own face
  component, drawable and independent visual occlusion.
- **Mechanical host chain**: canonical AXIS chain whose *actual final MIRA
  weights* kinematically move one or more pinned vertices. An instance may
  have pins tied to more than one chain in a future multi-host program;
  this v1 program admits exactly one qualified host chain.
- **Dynamic XPBD domain**: the remaining canonical vertices on the
  independently qualified OPEN component. Dynamic ownership and shared
  secondary joints remain disjoint under
  `qualify_mechanics_physics_domain_ownership_v1`.
- **Source/native witness**: independently verified native open boundary,
  face correspondence, pinned vertices and a held-out *host-only*
  intervention. UNKNOWN is not "no pin" and is not activation.
- **Graphics authority**: RGB/alpha, visibility and contour after motion.
  No source color/style truth is authorized by mechanics admission.

## Three-phase source-independent compile

1. **Candidate**: A separately compiled canonical mesh/rig/skin/Mechanics
   already exists, born from the same final TESSA M* (signed body and open
   surface). Every final canonical face carries its native parent face ID
   and three source-native barycentric corner addresses. One native face may
   parent multiple TESSA-refined triangles; corners, orientation, face order
   and target IDs are sealed in the transport digest. Native pin vertex IDs
   map separately to final canonical pin IDs. Nearest-neighbor or role-only
   guesses are forbidden.
2. **Evidence court**: `SourceQualifiedOpenSurfacePinProgramV1` must bind
   source asset, dataset manifest, final M* topology address, canonical mesh
   lineage, component, chain, full native OPEN boundary SHA, independent pin
   witness SHA, held-out host-only intervention SHA and source→canonical
   transport SHA. TWO independently trusted receipts are required:
   `QUALIFIED_SOURCE_NATIVE_OPEN_PIN_WITH_HOST_INTERVENTION` for source
   and `COMPILER_FINAL_MSTAR_TO_CANONICAL_REINDEX_VERIFIED` for Compiler.
   The final canonical OPEN hem edge digest must also be tied to the native
   source hem by the independent Compiler reindex receipt. A pin cannot
   silently activate physics on an unrelated OPEN boundary. All
   confidence/status fields must be explicit; generated 6 views, model
   slot IDs and material coefficients cannot pretend native truth.
3. **Executable Mechanics**:
   `prepare_source_qualified_open_surface_xpbd_v1` verifies the entire
   canonical component is a connected manifold OPEN sheet with degree-2
   boundary loops; non-manifold, cut, mixed, closed or orphan surfaces fail.
   Canonical pins must belong to the component and have positive support
   on an existing AXIS host chain through actual final skin weights.
   The existing `prepare_declared_xpbd_surface_domain_v1` and its hashes
   prepare the domain. **No new XPBD solver is created or automatically run.**
   The actual puppet session explicitly calls
   `enable_declared_xpbd_surface(domain,policy)`; a policy is a chosen
   runtime program and must not be presented as physically observed truth.

## Data handoff required from the other chat

The data pipeline can ultimately supply original native mesh/face/hem/pin
witnesses, verified host-only interventions and independent rights. It must
NOT choose canonical student M* indices directly. After the model produces
final M*, Compiler must independently reindex exact source witnesses and
record that transport in the second trusted receipt.

If the native asset has **no pins/physics program** or no observable cloth
intervention, the default is **ABSTAIN/UNKNOWN**, not synthetic NO_PIN,
automatic XPBD, manual random anchors, or a hard-coded cape policy.

## Current scope and remaining acceptance

This bridge admits one complete open manifold component with one mechanical
host chain and multiple pins. It is intentionally conservative: multi-host
cloth, cut boundary domains, partial garment patches, changing pins over
time, collisions against body mesh, artistic material calibration, and
swept-contact proof require separate proposals and held-out behavior tests.

Success proves a trusted program can enter *the actual editor* and move
the existing canonical surface. It does NOT prove that the model learned
ownership, produced a source-faithful cape, preserved RGB/alpha, or passed
release ProductProof. Test fixtures are synthetic regression artifacts
only; they are not production training examples.
