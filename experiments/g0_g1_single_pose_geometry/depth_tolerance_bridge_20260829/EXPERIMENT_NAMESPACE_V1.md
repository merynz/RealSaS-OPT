**Date:** 2026-08-29

This file exists to prevent collision between the historical IRIS qualification work previously referred to as “M4” and the current structured depth-tolerance bridge work.

## Canonical human-facing aliases

- **LEGACY-IRIS-M4** = the older IRIS qualification/generalization line. Historical only. Never call this simply `M4` in new continuation documents.
- **DTB-S1** = the current 65-cell structured depth surface/substrate grid whose sealed artifacts retain their original `M4_*` filenames for provenance.
- **DTB-S1R** = the current ALL8 boundary-refinement follow-up whose sealed artifacts retain their original `M4R_*` filenames for provenance.
- **DTB-ND1** = the prospective differential-normal-operator replay that compares the historical stride-2 cross-product `N_d` against the preregistered robust local-plane `N_d` while holding the depth corruption, population, persistence/proxy bytes, and decision margins fixed.

## Rule

Sealed artifact filenames are immutable. We do not rename or rewrite historical `M4_*` / `M4R_*` files. The aliases above are used only for future prose, reports, commit messages, and continuation state.

This naming change is semantic hygiene only; it does not alter any scientific result or decision operator.
