Start with the character you already designed. Good reference art helps our models understand its parts, proportions and structure — without asking you to redraw it.

INPUT / 01REQUIRED
FRONT / FULL CHARACTER

Start with the front.

Show the whole character in one image. Keep the head, hands and feet visible, with a pose where limbs can be distinguished.

INPUT / 02OPTIONAL
BACK / SAME CHARACTER

Add the back.

A matching back view can help clarify unseen shapes and details. Keep the scale, proportions and pose as consistent as possible.

INPUT / 03GOOD PRACTICE
CLEAN / READABLE / UNCROPPED

Make the shapes readable.

Prefer a clear silhouette and simple background. Heavy overlaps, hidden joints and cropped parts leave more uncertainty.

ARTWORK CHECK / NOT AN AUTOMATED VALIDATION
HELPS THE COMPILER

+ Whole character in frame

+ Visible, distinguishable limbs

+ Matching front and back proportions

CAN INTRODUCE UNCERTAINTY

− Cropped feet, hands or accessories

− Limbs hiding behind one another

− Conflicting views or extreme perspective

These are recommendations, not strict style rules. Unusual characters are welcome; uncertain regions may need additional review.
