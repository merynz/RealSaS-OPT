## Key diagnosis

V0/V1 both made a formulation error: every one of the 64 carriers was forced to choose a realization from its frozen `H_i` set, including carriers whose observable G support is already sharp/singleton-like. This destroys good baseline geometry and contaminates downstream mechanics.

The correct Rank-2 problem is **mixed**:

- sharp/singleton-like G carriers should remain fixed at the frozen real inference `P_B` and become relational anchors;
- only diffuse/set-valued carriers should be variable over observation-consistent alternatives;
- the frozen baseline realization should remain an explicit no-change option for every variable carrier so the global solver may decline to alter a carrier when relational evidence is insufficient.

This directly implements the scientific distinction: Rank-3 G is already a point; Rank-2 G is a feasible set.

1. an observation-only mixed singleton/set split derived from `H_i` uncertainty;
2. fixed singleton anchors;
3. a baseline/no-change candidate inside variable domains;
4. intrinsic relational addressing that is mechanically gated using frozen observable R evidence, so articulation boundaries are not treated as globally isometric.
