# Truth Foundry — Full Corpus Source Inspection / RSS.vNext Target Crosswalk v1

**Date:** 2026-11-10  
**Authority:** Audit and engineering *design proposal*, **not** training admission, target-count freeze, original-source parity or character semantic proof.  
**Architecture reference:** `canonical/RSS_VNEXT_UNIFIED_CHARACTER_ARCHITECTURE_FREEZE_V1_20261109.json` (draft PR #397).  
**Source identity reference:** V26 SHA-locked 16,397×264 matrix, 504/726 Master726 rehashed normalized derivative numeric courts. Protected holdouts unchanged.

## Why

The user requirement is **know each source as closely as having opened it, examined its native scene, inspected mesh/component/material/texture/pose/camera, and tested physical/semantic/graphics/mechanical capabilities**. A SHA record or mesh vertex count does not fulfill this. Every source gets 264 evidence facets, each with exactly scoped authority and an observation/court provenance. Every vNext training target must bind to sufficiently qualified facet evidence and further producer+consumer court; producer existence and metadata are not loss authorization.

## Measured crosswalk

- 16,397 unique source keys × exactly 264 existing facet states = **4,328,808** inspected matrix cells. Full source-key and facet count independently read back.
- Existing *formal* Corpus370 subject-family authority policy contains **14** truth families, not a frozen 37-target design. The architecture freeze establishes model/domain ownership but **does not freeze the target count**.
- **47 provisional candidate target contracts**: 43 neural targets (IRIS Geometry 6, IRIS Semantic 6, IRIS Graphics 8, TESSA 8, AXIS 9, MIRA 6), plus 4 compiler/graphics/mechanics qualification oracles. This is **not** a unilateral replacement of the 14 legacy policy families.
- For each of these 47 targets, record its canonical owner, legacy family (or `NEW_VNEXT`), required source facet signals, output type, and per-source **evidence-screen** status. **No table reports 47 target-specific trainer-admitted numbers**: the current 264-state metadata is insufficient to issue them.
- The source matrix includes **0 independently verified character-vs-prop verdicts and 0 independent training-rights gate passes** under those two facets. Therefore do not estimate 14k rig/skin training admits by equating 'has bone count' with 'court-qualified rig/skin weight target'.
- Facet inventory state includes partial historical or derivative evidence; `ALL_REQUIRED_SCOPED_DERIVATIVE_EVIDENCE_NOT_ADMITTED` is **still not a PASS**. Some source fields are weak claims, others are real measured derivative observations but not creator originals. `UNKNOWN` remains unknown.

## Measured deeper structural court on actually accessible normalized derivatives

- 138 disjoint *previously* SHA-verified numeric derivative pairs from V24 (20), V25 (36), and V26 (82) were **re-opened and independently rehashed**; not counted as 138 new Master726 courts.
- 1,572,811 vertices; 2,095,799 triangles; **1,228 mesh objects**; 6,538 normalized rig joints.
- **74/138** have multiple mesh objects; **126/138** have multiple index-connected triangle surface islands. Source object face assignment has zero cross-range triangles in this subset.
- 130,048 *index-connected* surface islands total; 56,647 unused/isolated vertices and 2,052 zero-sum skin vertices (not silently repaired). Many imported assets are face-soup or detached islands; neither index-island count nor object name equals an anatomical part, editable drawable, or unique physical owner.
- Boundaries 682,060, nonmanifold edges 1,091. All quality observations retained; they do not change the already independently verified V24–V26 numeric-pass status and do not establish watertight product mesh.
- This local audit **does not** reopen native FBX/GLTF original scenes, textures, material slots, animation curves or cameras, nor does it prove source-original parity, rights, front/back, character identity, morphology or render quality. These remain explicit native-scene court requirements for **all** 138.
- New review-priority queue is sorted by physical anomaly flags, **not** automatic rejection/semantic inference. 8 cases score >5; some have >100 mesh objects and >1000 topological islands.

## The required 'hand-inspected' production court

Each source must pass independent stages, with **per-stage and per-field typed evidence, not a blanket source PASS**:

1. **Source/rights/lineage:** original publisher URL/commit, package SHA, full source bytes/sidecars, exact license version/attribution/ML-training grant, AI-exclusion, family/dedup cluster, holdout, derivative equivalence. A scene import from a different package does not prove creator-original parity.
2. **Native DCC scene inspection:** open the *original* GLB/GLTF/FBX/OBJ/BLEND in a pinned offline worker; enumerate object+node transforms, actual mesh islands/face-corner lineage, materials+image pixels+UVs, armature/bone/rest/bind/weights, actions/keyframes/drivers, camera, source up-axis, units and original orientation. Preserve which values are absent/inapplicable.
3. **Rendered and native-frame inspection:** source-consistent diagnostic renders on native camera and canonical front/back/side (only after independently qualifying anatomical axes), mask/source-face ID/depth/alpha normals, visible/hidden coverage and silhouette. Inspect artifacts for actual character, type/morphology, attached prop, native pose, source-art style suitability. Ambiguous subjects remain review-queued, not guessed.
4. **Source truth builders:** conditional UDF (many), qualified global signed SDF/occupancy (only independently proven solids), exact/source image addresses, semantics/instances/affordances with abstention, structural mesh/charts/relations, rig parent/rest/control targets, skin dense+sparse with exact carrier, multi-pose deformation, graphics visibility and edit consequence. All row-level validity masks and post-repair provenance retained.
5. **Independent consumer courts:** by family, verify exact physical and semantic target, target masks and teacher/source/student separation; no source object names or provider marketing promoted into semantic truth. Compiler oracle results are a different target class from neural training tensors.
6. **Admission/split/materialization:** rights, true-character gate (or explicitly qualified non-character use where permitted), source/renderer QA, ontology decisions, lineage cluster, one product global unseen split before all training, model-specific partial family admissions, source hash-binding, sealed training shard manifests, independent readback.

**Training readiness:** until actual producers/consumer courts and rights/semantic/native-scene inspections are complete, all target counts are *unknown*, not zero and not a 14k marketing estimate. Aim for thousands of usable target subjects wherever source proves them, but accept genuine physical masks: modular/open geometry may contribute tens of thousands of UDF/skin/rig targets with **no globally signed SDF**.
